# 50 Nights — web app

Play: **https://kusovnazar.github.io/50nights/**

On iPhone: open the link in Safari → Share → **Add to Home Screen**. On Android (Chrome): menu → **Install app**.
The game then starts from its own icon, full screen, also offline; new versions download by themselves
(the menu offers «Нова версія готова · оновити»).

This repository holds only the built game (Godot web export, made by `tools/pwa_build.sh` in the game's
source repository). `version.txt` is the source commit it was built from.
